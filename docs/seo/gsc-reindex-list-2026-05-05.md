# GSC Re-indekseringsliste — 5. mai 2026

Generert etter at JSON-LD-migrering ble ferdigstilt 30. april. **43 URLer totalt.**

GSC URL Inspection-quoten er typisk **10-15 manual submissions/dag/property**. Listen er prioritert så de viktigste tar første dag.

**Hvordan re-indeksere:**
1. Åpne [Google Search Console](https://search.google.com/search-console?resource_id=sc-domain%3Afosen-tools.no)
2. Klikk URL-inspeksjon-feltet øverst
3. Lim inn én URL fra listen → Enter
4. Klikk **"Be om indeksering"**
5. Vent ~30-60 sekunder (Google sjekker live)
6. Bekreftelse: "Indeksering forespurt" → strøk over i listen
7. Gå til neste URL

**Tips:**
- Quoten resettes typisk innen 24t — fordel listen på 4-5 dager
- Hvis URL-inspect viser "URL is not on Google" → siden er enten blokkert (sjekk robots.txt + canonical) eller ikke i sitemap
